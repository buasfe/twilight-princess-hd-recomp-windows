# Windows Preview — 20th Anniversary

The first Windows source preview is for the 20th anniversary of Twilight Princess’s original North American Wii launch. It brings AsadSi’s Twilight Princess HD recompilation to Windows 11 x86-64 with a Vulkan runtime, extending work from ZeldaWWHDRecomp and its contributors.

The preview was tested with an RTX 3070 at 21:9 and 2× internal resolution. It includes Xbox controller fixes for Wii U GamePad and Pro Controller modes, F1 stick navigation, and the original 30 Hz simulation with optional interpolated presentation. Hardware and full-game progression coverage are limited. Intermittent high-FPS UI animation and occasional white flicker remain open for investigation.

Build locally from a USA Wii U disc dump, Rev 2, version 81. Use the source archive generated by GitHub and follow the Windows build guide. The source preview uses the MPL-2.0 licence and carries the upstream and third-party notices. [Windows build guide](windows.md) · [Credits](../CREDITS.md)

Controller-specific glyphs and the limited Ordon 60 Hz simulation work remain separate development efforts.
